# Видео Dharma для Joomla

Повторяемое поле материала: ссылка на VK Видео или Rutube и необязательная подпись.
В админке предпросмотр появляется после вставки ссылки и при повторном открытии материала. На странице материала плееры
выводятся плитками в порядке строк: одна, две или три колонки на широком экране,
одна на телефоне. Плееры загружаются при нажатии; рядом остаются прямые
ссылки на ролики.

Проверено на Joomla 6.2 с PHP 8.4.

## Установка и настройка

1. Скачайте установочный ZIP на странице [релизов](https://github.com/shivayanamahom/plg_fields_dharmavideo/releases/latest) и загрузите его через «Система → Установка → Расширения».
2. Включите плагин «Поля — Видео Dharma».
3. В разделе «Материалы → Поля» создайте необязательное поле типа
   «Видео (VK Видео и Rutube)». Назначьте нужным категориям или оставьте
   доступным для всех материалов. Для автоматической вставки включите
   «После содержимого» на вкладке параметров отображения. В настройке
   «Открытие видео» выберите «В карточке» или «В окне WT Fancybox». Второй
   режим использует установленный и включённый плагин WT Fancybox; без него
   видео откроется в карточке.
4. Откройте материал, перейдите на вкладку «Поля» и нажмите «+» в поле «Видео».
   Вставьте ссылку на ролик из адресной строки или меню «Поделиться». Плеер
   автоматически появится под полем ссылки, воспроизведение запускается вручную.

Поддерживаются прямые ссылки VK / VK Видео, ссылки с `z=video…`, ссылки
Rutube на ролики и Shorts, а также адреса плееров обоих сервисов.
Если в адресе есть поддерживаемый ключ доступа (`p` или `hash`), он
передаётся плееру. Возможность просмотра управляется самим видеосервисом.
На один материал можно добавить до 20 строк на поле. Для удаления ролика
удалите его строку и сохраните материал.

Разметка плееров переопределяется в `templates/<шаблон>/html/plg_fields_dharmavideo/dharmavideo.php`.
При сохранении материала плагин получает доступные обложки с площадок,
уменьшает их до 1280 пикселей по большей стороне и сохраняет JPEG в
`images/dharmavideo/posters/`. Для этого нужны PHP GD, разрешённые HTTPS-запросы
из PHP и право записи в каталог. Если обложку получить не удалось, сам ролик
остаётся доступен; загрузка обложки повторится при следующем сохранении.
На страницах сайта запросов к API площадок нет. Когда обе позиции Joomla
«Вводное изображение» и «Полное изображение» пусты, обложка первого ролика
подставляется при выводе. Штатные поля изображений в базе не меняются.

### Ручной вывод в шаблоне

Чтобы самому выбрать место вывода, установите параметр поля
«Автоматическое отображение» в положение «Не отображать автоматически».
Вставьте код ниже в переопределение статьи
`templates/<шаблон>/html/com_content/article/default.php`, в ветку с
`$this->item->params->get('access-view')`. Замените `video-materiala`
на системное имя своего поля.

```php
<?php
foreach ($this->item->jcfields ?? [] as $field) {
    if ($field->name === 'video-materiala' && $field->type === 'dharmavideo') {
        echo $field->value;
        break;
    }
}
?>
```

Joomla передаёт в `value` подготовленный HTML. Сетка использует классы
Bootstrap 5. Для своей разметки можно переопределить
`templates/<шаблон>/html/layouts/plg_fields_dharmavideo/gallery.php` и
`launch.php`, взяв за основу файлы из `layouts/plg_fields_dharmavideo/`.

### Как работает WT Fancybox

Установите и включите системный плагин WT Fancybox. В настройках поля
выберите «Открытие видео» → «В окне WT Fancybox». Поле подключает
зарегистрированный поставщиком пресет `wtfancybox`. Плитка содержит
разрешённый адрес плеера и открывает его как iframe по нажатию.
Та же настройка действует в шапке Smart Clinic. Белые отступы убраны
только вокруг видео. Если WT Fancybox недоступен, плеер откроется в карточке.

### Шаблон Smart Clinic

Патч и макеты лежат в `integrations/smart_clinic/`. Примените
`article-layouts.patch` из корня сайта с `patch -p1` и скопируйте оба файла
`clinic-article-video*.php` в `templates/smart_clinic/html/layouts/`.
В параметрах поля выберите «Не отображать автоматически». Для карточек
модуля «Материалы» включите «Вызов событий плагинов».

В стандартном макете материала без редакционного фото первый ролик
появляется в шапке с кнопкой воспроизведения. В блок «Видео» попадают
оставшиеся ролики. При выборе фото Joomla показывает его в шапке и тизере,
а все ролики выводятся в блоке «Видео». Кнопки в обоих местах используют
выбранный в поле режим открытия.
